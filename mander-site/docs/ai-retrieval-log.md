# AI retrieval log — web-search proxy, not a live AI query

## What this is

Every row below comes from **Claude's own web search**, run against a fixed prompt list once a
month. That is a proxy for what an AI system might surface about MANDER — it is genuinely useful
for catching a wrong or missing fact early (this is exactly how the `herman@mander.tech` email
error surfaced earlier in this project's history) — but it is **not** the same as querying
ChatGPT, a Google AI Overview, or Perplexity directly. No API access exists to any of those from
this environment. Read every row here with that in mind, and don't mistake it for a citation-share
number — that's what `docs/ai-visibility.md` is for.

## Fixed prompt list

Reused from the brief that proposed this, filled in with MANDER's real focus rather than a
placeholder:

1. Who are some web design agencies serving Metro Vancouver?
2. What agencies specialize in websites for small businesses in Vancouver?
3. What does MANDER do?
4. What services does MANDER provide?
5. Is MANDER a web design company?
6. Which web designers are mentioned for Metro Vancouver?
