# AI visibility tracking

A record of where MANDER is (and isn't) cited by AI systems, and how that changes over time.

## What this is, and isn't

The **Citation share** column is Microsoft's own metric, computed inside Bing Webmaster Tools'
AI Performance report (Intents / Topics / Citation Share / Compare — public preview since
June 2026). It is entered here **by hand, from a Bing Webmaster Tools export or API pull** — it
is never generated by anyone editing this file. Nothing in this repository can compute it.

Bing Webmaster Tools is already verified for mander.tech. What's still needed to populate this
table automatically is either an API key from that account, or a habit of dropping in the CSV
export periodically. Until one of those exists, add rows by hand after checking the dashboard
directly.

This table does not cover ChatGPT, Google AI Overviews, Perplexity or any system Bing doesn't
see into — those aren't measurable this way. `docs/ai-retrieval-log.md` covers those, as an
explicitly-labeled web-search proxy rather than real citation data.

## How to add a row

1. Open Bing Webmaster Tools → AI Performance → Citation Share for mander.tech.
2. For each query/topic worth tracking (start with the ones already named in
   `lib/pillars.js` and `lib/locations.js` — brand/digital/growth, the eight Metro Vancouver
   cities, and the service names in `lib/content.js` `SERVICES`), copy the row as shown.
3. Set **Change** by comparing against the previous **Citation share** value for the same query —
   leave blank on a query's first entry.
